## 💫 About Me

I'm **Alex Steven Ponluisa Brito**, a Full Stack Software Engineer from **Ambato, Ecuador** 🇪🇨 and a Software Engineering student at **Universidad Técnica de Ambato (FISEI)**.
I build complete web and mobile applications — from clean frontends to solid backends and the databases behind them.

- 💼 Currently working at **EEASA** (electric utility) across full-stack development, database administration and IT support
- 🎓 Thesis: gym management system with **computer-vision anthropometric measurement** (MediaPipe + FastAPI + Blazor)
- 🏁 Competing in **Hackathon Expo Clean 2026** with team *Los Kubernetes*
- 🔭 Open to **Full Stack Developer** opportunities — remote or on-site
- 🎮 Avid gamer and traveler when not coding
